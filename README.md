# Tuesday Echo — News of 24 November 2026

A one-page newspaper front page summing up Tuesday 24 November 2026 in six verified stories: Nvidia's Jensen Huang returns and shares soar 31%, Ukraine sinks a Russian warship off Libya, COP31 collapses with no deal, Iran vows to fight the US blockade, the World Chess Championship begins in Geneva, and 24 die in an Indonesian factory fire.

The image is drawn from scratch with Pillow (`draw.py`, no photos or external assets); `main.ts` copies `entry.png` to the output directory. To redraw the image, run `python3 draw.py` — it is deterministic, so repeated runs produce byte-identical output.
